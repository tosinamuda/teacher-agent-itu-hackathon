# Write the lesson-wide lists

Each list is optional. Give one only where the teacher's source or the lesson supports it.

- **Theme**: the lesson's curriculum theme, only when the source names one.
- **Entry behaviour**: what the students already know or can do from earlier lessons. Write
  "The students can add whole numbers", not "The students will learn fractions". The
  introduction recalls these.
- **Instructional materials**: what the teacher uses in the lesson, such as a chalkboard, a
  ruler or fraction cards. List only materials the source or the curriculum names. Never
  invent a textbook page, a worksheet or an answer key.
- **Misconceptions**: mistakes students are likely to make in this lesson, for the teacher to
  address. Write the mistake itself: "Adding the denominators: 1/4 + 2/4 = 3/8."
- **References**: the textbooks and sources the lesson draws on. Never invent a book, an
  edition or a page.
