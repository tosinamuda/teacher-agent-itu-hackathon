# Use the lesson's figures

- Put a drawing in `figures` only when the lesson's plan or lesson note draws it for this
  objective. Copy it exactly as the lesson draws it, with the same labels.
- Never draw a new figure. A drawing the lesson does not have is left out.
- A drawing is one tikzpicture environment. Its caption names what it shows and its
  labelled points, and the text uses the same labels.
- Refer to a drawing only when it is in `figures`. Never write "as shown in the diagram"
  for a drawing the section does not hold.
- A construction the lesson taught keeps its numbered steps, for ruler and compasses,
  exactly as the lesson gives them.
