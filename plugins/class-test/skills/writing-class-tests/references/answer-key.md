# Key the correct option

The test is marked by the letter the learner picks. A key that is wrong, or a second right
option, marks a right answer as wrong.

- Solve the question yourself before you key it. The correct option must be mathematically
  correct.
- Exactly one option is right by the lesson. Read each wrong option as the teacher of this
  lesson would mark it. If it is also right, replace it.
  - Wrong: "Which is an improper fraction?" keyed $\frac{8}{5}$, with $\frac{4}{4}$ among the
    wrong options, in a lesson that calls a fraction improper when its numerator is greater
    than or equal to its denominator.
  - Right: the same stem with $\frac{8}{5}$ and wrong options $\frac{3}{4}$, $\frac{1}{2}$ and
    $\frac{5}{8}$.
- No two options say the same thing, in the same or another form. Never offer
  $\frac{1}{2}$ and $\frac{2}{4}$, or $0.5$ and $\frac{1}{2}$, as two options of one question.
- `correct_option` is the letter of the option that holds the answer.
- Spread the correct letter: across the lesson's questions, the answer is not always at A.
