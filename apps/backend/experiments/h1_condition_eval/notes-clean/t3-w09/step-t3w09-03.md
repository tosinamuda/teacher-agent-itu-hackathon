#### Collection of Data

Data can be collected through

1. observation
2. counting
3. Interview
4. Questionnaire.

#### Tally Marks

Tally Marks are used to record data as they are collected.

**Example:** The fig below show the same data collected in two different ways by two student

(a) bus, car, car, car, lorry, bicycle, bicycle, car, car, lorry, bicycle, car.

The above data can be represented in Tally

#### Frequency Table

A frequency table is a table showing how many times each item occurs in a set of data.

**Examples:**

Favourite colours of student:

| colour | frequency |
|---|---|
| Red | 18 |
| Blue | 20 |
| Green | 14 |
| Yellow | 16 |
| White | 15 |
| Pink | 30 |
