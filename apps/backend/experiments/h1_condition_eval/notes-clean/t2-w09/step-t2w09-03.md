**Hints**

- Always try to simplify the terms inside bracket first.
- A $+$ sign before a bracket does not change the signs of the terms inside the bracket, when
  bracket is removed.
- A $-$ sign before a bracket will change all the $+$ sign inside the bracket to $-$ and also
  change all the $-$ sign inside the bracket to $+$ when the bracket is removed.

#### Example 1. Simplify

(a) $a + (b + c)$

(b) $a + (b - c)$

(c) $2a - (3b - c)$

**Solution**

(a) $a + (b + c) = a + b + c$

(b) $a + (b - c) = a + b - c$

(c) $2a - (3b - c) = 2a - 3b + c$

#### Example 2. Simplify

(a) $a + (a - b)$

(b) $6x + (3 - x)$

(c) $(3a + 2) + (5a + a)$

**Solution**

(a) $a + (a - b)$

$= a + a - b$

$= 2a - b$

(b) $6x + (3 - x)$

$= 6x + 3 - x$

$= 6x - x + 3$

$= 5x + 3$

(c) $(3a + 2) + (5a + a)$

$= 3a + 2 + 5a + a$

$= 3a + 5a + a + 2$

$= 9a + 2$

#### Example 3. Simplify the following

(a) $5x - (3y + z)$

(b) $10d - (9c - 4d)$

(c) $(6x - y) - (4x - 5y)$

**Solution**

(a) $5x - (3y + z)$

$= 5x - 3y - z$

(b) $10d - (9c - 4d)$

$= 10d - 9c + 4d$

$= 10d + 4d - 9c$

$= 14d - 9c$

(c) $(6x - y) - (4x - 5y)$

$= 6x - y - 4x + 5y$

$= 6x - 4x + 5y - y$

$= 2x + 4y$

$= 2(x + 2y)$
