## Source: step-t2w09-02 — Step 1 — order of operations

#### Example 1. Find the value of the following

(a) $18 - 6 \times 2$

(b) $6 - 18 \div 3$

(c) $6 \times 2 - 2 - 40 \div 4$

**Solution**

(a) $18 - 6 \times 2$

$= 18 - 12$

$= 6$

(b) $6 - 18 \div 3$

$= 6 - 6$

$= 0$

(c) $(6 \times 2) - 2 - (40 \div 4)$

$= 12 - 2 - 10$

$= 10 - 10$

$= 0$

#### Example 2. Simplify the following

(a) $3x \times 2 + 5x$

(b) $17y - 5 \times 2y$

**Solution**

(a) $3x \times 2 + 5x$

$= 6x + 5x$

$= 11x$

(b) $17y - 5 \times 2y$

$= 17y - 10y$

$= 7y$

#### Example 3. Simplify the following

(a) $7x \div x + 5$

(b) $4x - (6 \div 3)$

(c) $(24x \div 6) + x + (1 \times 5x)$

**Solution**

(a) $7x \div x + 5$

$= \frac{7x}{x} + 5$

$= 7 + 5$

$= 12$

(b) $4x - (6 \div 3)$

$= 4x - 2$

(c) $(24x \div 6) + x + (1 \times 5x)$

$= 4x + x + 5x$

$= 5x + 5x$

$= 10x$

## Source: step-t2w09-03 — Step 2 — insertion and removal of brackets

**Hints**

- Always try to simplify the terms inside bracket first.
- A $+$ sign before a bracket does not change the signs of the terms inside the bracket, when
  bracket is removed.
- A $-$ sign before a bracket will change all the $+$ sign inside the bracket to $-$ and also
  change all the $-$ sign inside the bracket to $+$ when the bracket is removed.

#### Example 1. Simplify

(a) $a + (b + c)$

(b) $a + (b - c)$

(c) $2a - (3b - c)$

**Solution**

(a) $a + (b + c) = a + b + c$

(b) $a + (b - c) = a + b - c$

(c) $2a - (3b - c) = 2a - 3b + c$

#### Example 2. Simplify

(a) $a + (a - b)$

(b) $6x + (3 - x)$

(c) $(3a + 2) + (5a + a)$

**Solution**

(a) $a + (a - b)$

$= a + a - b$

$= 2a - b$

(b) $6x + (3 - x)$

$= 6x + 3 - x$

$= 6x - x + 3$

$= 5x + 3$

(c) $(3a + 2) + (5a + a)$

$= 3a + 2 + 5a + a$

$= 3a + 5a + a + 2$

$= 9a + 2$

#### Example 3. Simplify the following

(a) $5x - (3y + z)$

(b) $10d - (9c - 4d)$

(c) $(6x - y) - (4x - 5y)$

**Solution**

(a) $5x - (3y + z)$

$= 5x - 3y - z$

(b) $10d - (9c - 4d)$

$= 10d - 9c + 4d$

$= 10d + 4d - 9c$

$= 14d - 9c$

(c) $(6x - y) - (4x - 5y)$

$= 6x - y + 4x + 5y$

$= 6x - 4x + 5y - y$

$= 2x + 4y$

$= 2(x + 2y)$

## Source: step-t2w09-04 — Step 3 — word problems involving algebraic expressions

#### Example 1

A pen cost $P$ naira and a pencil cost 15 naira less than a pen.

(a) Find the cost of a pencil

(b) Find the cost of a pen and a pencil

**Solution**

Cost of a pen $= ₦P$

(a) cost of a pencil $= ₦(P - 15)$

(b) So cost of a pen and a pencil $= ₦P + ₦(P - 15)$

$= ₦P + ₦P - ₦15$

$= ₦2P - ₦15$

$= ₦(2P - 15)$

#### Example 2

A pencil cost $x$ naira and a rubber cost 40 naira more than a pencil.

(a) find the cost of a rubber

(b) find the cost of a pencil and a rubber

**Solution**

(a) cost of a pencil $= ₦x$

$\therefore$ cost of a rubber $= ₦(x + 40)$

(b) cost of a pencil and a rubber:

$= ₦x + ₦(x + 40)$

$= ₦(x + x + 40)$

$= ₦(2x + 40)$

#### Example 3

In a class, there are $x$ boys and $y$ girls last semester. This semester, 5 boys join and
3 girls leave the class. How many students are now in this class?

**Solution**

Total no $=$ number of boys $+$ number of girls

Number of boys $= x + 5$

Number of girls $= y - 3$

Total number $= x + 5 + y - 3$

$= x + y + 5 - 3$

$= x + y + 2$
