## The revision pack

### What Statistics Is For

Every day you meet information all around you: how many learners came to school, how many goals a team scored, how much rain fell in a week, how many people voted. On its own, a jumbled list of such facts is hard to make sense of. Statistics is the method of <strong>collecting</strong> and <strong>organising</strong> information so that it can be understood and used.

Its purpose is not to gather numbers for their own sake. When information is collected and arranged neatly, it becomes easy to see what is happening, to compare one thing with another, and to make sensible decisions. A teacher collects the number of learners present each day; arranged in order, that information shows which day of the week attendance was best. A shopkeeper records what was sold; organised into a table, it shows which items are most wanted. This is what statistics is <em>for</em>: turning scattered information into something clear enough to read and act on.

So the heart of statistics is two steps: <strong>collecting</strong> the information, and <strong>organising</strong> it so that its meaning can be seen.

Suppose a class wants to know which colour of pencil is most common among its learners. First the information is <strong>collected</strong>: each learner names their pencil colour — blue, red, blue, green, red, blue, blue, green, red, blue. That list alone is hard to read, so the information is then <strong>organised</strong>.

Write each colour once, and count how many times it appears:

- Blue: 5
- Red: 3
- Green: 2

Now the meaning is clear at a glance: blue is the most common pencil colour. Statistics collected the information and organised it so a decision — which colour to buy more of — could be made easily.

**Practice**

1. Explain in your own words what statistics is, and state its two main steps.

2. A gardener notes the number of tomatoes picked from a plant each day: 4, 6, 4, 5, 6, 4, 5, 6. Organise this information by counting how many times each number appears.

### From Tallies to a Frequency Table

When a statistician wants to find out something — say, how many brothers and sisters your classmates have, or how many bottles were collected for recycling — the first thing to do is collect the information. Every single piece of information you gather is called a piece of <strong>data</strong>. But a long list of numbers is hard to read at a glance. To understand it, you need to organise it into a table, and the most useful table for this is a <strong>frequency table</strong>.

A <strong>frequency table</strong> records three things for each different value: the value itself, how you counted it using <strong>tally marks</strong>, and the <strong>frequency</strong> — the number of times that value appears.

Let's look at how tally marks work. Each time a value appears, you draw one short vertical stroke <strong>|</strong>. When you reach the fifth mark, you draw it across the four as a diagonal stroke, making a bundle of five: <strong>||||</strong>. This bundle makes it much easier to count your marks at the end. So:

- four marks are <strong>||||</strong> (four strokes)
- five marks are <strong>||||</strong> (four strokes and one across)
- seven marks are <strong>|||| ||</strong>
- ten marks are <strong>|||| ||||</strong>

To build a frequency table, you go through your data one value at a time. For each value you meet, find its row in the table and add one tally mark. When you have finished the whole list, you count the tallies in each row and write that number in the frequency column. The tally and the frequency must always match, so counting carefully is the whole skill.

Let's follow one small collection of data all the way through. Ten students recorded how many pencils each had on their desk, and here is the list:

3, 1, 2, 3, 1, 3, 2, 1, 3, 2

There are ten students, so there are ten numbers. The values that appear are 1, 2 and 3. We set up a frequency table with a row for each of these values.

Start with a blank tally column. Now go through the list in order and add a mark each time a value appears.

- First number is <strong>3</strong>: add one mark in row 3.
- Next is <strong>1</strong>: add a mark in row 1.
- Next is <strong>2</strong>: add a mark in row 2.
- Next is <strong>3</strong>: add a mark in row 3.
- Next is <strong>1</strong>: add a mark in row 1.
- Next is <strong>3</strong>: add a mark in row 3.
- Next is <strong>2</strong>: add a mark in row 2.
- Next is <strong>1</strong>: add a mark in row 1.
- Next is <strong>3</strong>: add a mark in row 3.
- Last is <strong>2</strong>: add a mark in row 2.

Now count each row of tallies.

- Row 1: three marks, so frequency 3.
- Row 2: three marks, so frequency 3.
- Row 3: four marks, so frequency 4.

The completed frequency table looks like this:

| Number of pencils | Tally | Frequency |
|---|---|---|
| 1 | \|\|\| | 3 |
| 2 | \|\|\| | 3 |
| 3 | \|\|\|\| | 4 |
| <strong>Total</strong> |  | <strong>10</strong> |

Check your work: the frequencies should add up to the total number of pieces of data. Here 3 + 3 + 4 = 10, and there were indeed ten students. If they did not add up, you missed a mark or counted one wrongly — go back and find the mistake.

Here is a complete example for you to follow. Twelve students in a class were asked their shoe size, and the results were recorded as follows:

6, 7, 5, 6, 6, 7, 5, 6, 7, 5, 6, 7

<strong>Step 1 — Set up the table.</strong> The values that appear are 5, 6 and 7, so give each its own row.

<strong>Step 2 — Tally the data.</strong> Go through the list in order and add one mark per value.

- 6: one mark in row 6
- 7: one mark in row 7
- 5: one mark in row 5
- 6: one mark in row 6
- 6: one mark in row 6
- 7: one mark in row 7
- 5: one mark in row 5
- 6: one mark in row 6
- 7: one mark in row 7
- 5: one mark in row 5
- 6: one mark in row 6
- 7: one mark in row 7

<strong>Step 3 — Count the tallies.</strong>

- Row 5 has four marks, so frequency 4.
- Row 6 has five marks (a full bundle of five), so frequency 5.
- Row 7 has three marks, so frequency 3.

<strong>Step 4 — Check the total.</strong> 4 + 5 + 3 = 12, which matches the twelve students. The table is correct.

| Shoe size | Tally | Frequency |
|---|---|---|
| 5 | \|\|\|\| | 4 |
| 6 | \|\|\|\|\| | 5 |
| 7 | \|\|\| | 3 |
| <strong>Total</strong> |  | <strong>12</strong> |

Once the table is complete you can read answers straight off it. The most common shoe size is 6, because it has the highest frequency (5). Five students wore size 6, four wore size 5, and three wore size 7.
