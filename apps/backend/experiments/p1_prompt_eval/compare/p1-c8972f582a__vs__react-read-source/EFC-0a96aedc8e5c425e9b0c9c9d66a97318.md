#### Ordering fractions – ascending order

*explanation*

To place fractions in order, first rewrite them with a common denominator; then the fraction with the smallest numerator is the smallest value. The textbook demonstrates ordering fractions directly (see REF‑1).

*worked_example*

**Worked example**

Fractions to order (from REF‑2): \(\frac{8}{9}, \frac{11}{12}, \frac{5}{6}\).
1. Find the LCD of 9, 12, and 6 → LCD = 36.
2. Convert each fraction:
   - \(\frac{8}{9} = \frac{8\times4}{9\times4} = \frac{32}{36}\)
   - \(\frac{11}{12} = \frac{11\times3}{12\times3} = \frac{33}{36}\)
   - \(\frac{5}{6} = \frac{5\times6}{6\times6} = \frac{30}{36}\)
3. Compare the numerators (30, 32, 33). Ordering from smallest to largest gives \(\frac{30}{36}, \frac{32}{36}, \frac{33}{36}\), which simplifies back to \(\frac{5}{6}, \frac{8}{9}, \frac{11}{12}\).

This follows the conversion process outlined in the textbook.

### Candidate B
#### Ordering fractions – ascending order (extended)

*explanation*

When fractions share the same denominator, the numerator directly indicates their size. To compare fractions we first find a common denominator—usually the least common denominator (LCD)—so that all fractions are expressed on the same scale. Then we can order them simply by comparing the numerators.

_Sources: REF-1_

*explanation*

**Worked example**

1. Fractions: \(\frac{3}{8}, \frac{1}{4}, \frac{5}{12}\).
2. LCD of 8, 4, 12 is 24.
3. Convert:
   - \(\frac{3}{8}=\frac{9}{24}\)
   - \(\frac{1}{4}=\frac{6}{24}\)
   - \(\frac{5}{12}=\frac{10}{24}\)
4. Compare numerators (6, 9, 10) → ascending order \(\frac{6}{24}, \frac{9}{24}, \frac{10}{24}\), which returns to \(\frac{1}{4}, \frac{3}{8}, \frac{5}{12}\).

### Candidate A
#### Arrange fractions in descending order (extended)

*explanation*

To order fractions from largest to smallest, find a common denominator (the LCD) and rewrite each fraction with that denominator.  Because the fractions are equivalent, the ordering can then be decided simply by comparing the numerators.  The textbook example in REF‑3 shows this process for \(\frac{5}{8}, \frac{8}{14}, \frac{18}{28}\).

*worked_example*

**Worked example (slightly harder)**

Find the descending order of \(\frac{7}{12}, \frac{3}{8}, \frac{5}{9}\).

*Step 1 – LCD*: The denominators 12, 8, 9 have LCD 72.
*Step 2 – Convert*:
- \(\frac{7}{12}=\frac{7\times6}{12\times6}=\frac{42}{72}\)
- \(\frac{3}{8}=\frac{3\times9}{8\times9}=\frac{27}{72}\)
- \(\frac{5}{9}=\frac{5\times8}{9\times8}=\frac{40}{72}\)
*Step 3 – Compare numerators*: 42, 40, 27 → descending order is \(\frac{7}{12} > \frac{5}{9} > \frac{3}{8}\).

2. Rewrite each fraction with that denominator.
3. List the fractions from the largest numerator to the smallest.
(Recall that equivalent fractions retain the same value – see REF‑1.)

### Candidate B
#### Arrange fractions in descending order

*explanation*

When we need to order fractions from largest to smallest we first rewrite them with a common denominator. Using the least common denominator (LCD) gives equivalent fractions that share the same denominator, so the order is decided simply by comparing the numerators. This idea of equivalent fractions is explained in Chapter 4 (REF‑1) and the method for finding the LCD is outlined in the textbook (REF‑2). The descending‑order example in the book (REF‑3) follows the same steps.

*worked_example*

**Worked example (from the textbook)**
1. **Find the LCD** – denominators 8, 14, 28 → LCD = 56.
2. **Convert each fraction**
   - \(\frac{5}{8}=\frac{35}{56}\)
   - \(\frac{8}{14}=\frac{32}{56}\)
   - \(\frac{18}{28}=\frac{36}{56}\)
3. **Compare numerators** – 36 > 35 > 32, so \(\frac{18}{28} > \frac{5}{8} > \frac{8}{14}\).
This mirrors the textbook exercise (REF‑3).
