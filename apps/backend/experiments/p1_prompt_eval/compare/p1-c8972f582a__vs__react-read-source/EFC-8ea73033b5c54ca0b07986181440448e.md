#### Counting in Billions (Extended)

*explanation*

A **billion** is the number 1 000 000 000. It can be written as 10⁹ because it is ten raised to the ninth power. Each step up the naming scale (thousand, million, billion) multiplies the previous value by ten.

*explanation*

The final stretch from 999,999,900 up to 1,000,000,000 shows how the last hundred‑million transitions to the exact billion. Numbers increase by 100 across each row and by 1,000 down each column.

*worked_example*

Let’s count the last few numbers before a billion:
1. 999,999,990
2. 999,999,991
3. 999,999,992
⋯
9. 999,999,999
10. **1,000,000,000** – this is the billion.
If each number represented a second, a billion seconds would be about 31.7 years, illustrating the magnitude of a billion.

## Objective lop03

### Candidate A
#### Write numbers in millions

*explanation*

One million equals 1,000,000 (10⁶). When a number is written in millions we are indicating how many groups of one million are present. For instance, 0.835 million means 0.835 × 1,000,000 = 835,000.

*worked_example*

Convert the following:
1. 0.835 million → move the decimal six places right → **835,000**.
2. 20.05 million → move the decimal six places right → **20,050,000**.
These conversions follow the same principle used when counting numbers in millions.

*practice*

### Candidate B
#### Writing billions in digits and words

*explanation*

A **billion** is one thousand million. In digits it is written as **1,000,000,000**. When a number contains billions, write the billions digit(s) left of the comma that separates the millions, then continue with the millions, thousands and units. For example, **2 billion 350 million 120 thousand 5** becomes **2,350,120,005**.

*worked_example*

**Worked example:** Convert **0.15 billion** to digits and words.

1. Recognise that 0.15 billion = 0.15 × 1,000,000,000.
2. Multiply: 0.15 × 1,000,000,000 = **150,000,000**.
3. Digits: **150,000,000**.
4. Words: **one hundred fifty million** (the result is expressed in millions because it is less than a full billion).

Thus, 0.15 billion = 150,000,000 = *one hundred fifty million*.
