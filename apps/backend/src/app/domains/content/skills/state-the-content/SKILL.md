---
name: State the content
description: Use for any content the class reads or copies down, so it states the subject itself instead of directing or narrating the lesson.
revision: 1
---
State the subject matter itself, as it is written for the class. The plan's activities already
hold what the teacher and the pupils do, so the content never says who does what.

- Write "A minus sign before a bracket changes the sign of every term inside it when the bracket
  is removed.", never "The teacher explains what happens to the signs."
- Never begin a line with a direction to the teacher, such as Ask, Show, Demonstrate, Emphasise
  or Recall.
- Never describe the lesson as an event: no "in this step", no "pupils will".
- A definition is given in full, never only referred to.
