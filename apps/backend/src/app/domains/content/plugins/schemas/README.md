# Agent Plugins schemas

`plugin.schema.json` and `mcp.schema.json` are copied unchanged from
[agentplugins/agent-plugins-spec](https://github.com/agentplugins/agent-plugins-spec)
(`schemas/1.0.0/`), Agent Plugins version 1.0.0. The project licenses its schemas under the
Apache License 2.0, in `Apache-2.0.txt` here. To move to a new version, copy that version's
files and update the version in `app/domains/content/plugins/standard.py`.
